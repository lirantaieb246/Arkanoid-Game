# Arkanoid-Game

Java implementation of the classic Arkanoid/Breakout arcade game built using object-oriented programming principles.

## Features

- Collision detection system
- Ball and paddle physics
- Brick destruction mechanics
- Score tracking
- Multiple geometry and collision classes
- Event-driven game loop
- Object-oriented architecture

## Technologies Used

- Java
- biuoop graphics library

## Project Structure

- `geometry` → geometric shapes and math utilities
- `collision` → collision detection and collision info
- `sprites` → game objects and rendering
- `listeners` → event handling system
- `objects` → game entities and gameplay objects

## How to Run

Run `Ass5Game.java` to start the game.
